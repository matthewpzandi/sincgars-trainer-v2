# SINCGARS Integrated Trainer

A Vite + React classroom trainer mockup for a SINCGARS-style assembly and single-channel setup sequence.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Push this repo to GitHub, then import it into Vercel as a Vite project. The default build command is:

```bash
npm run build
```

The output directory is:

```bash
dist
```
